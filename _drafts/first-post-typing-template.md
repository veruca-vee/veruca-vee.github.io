# Type it yourself: "The sequence that can't loop"

This is a typing template, not a draft. Every word of the post will be yours —
that's the whole point. I only built the boxes.

## How to use this

- **One sitting = one or two boxes.** Then stop, even if it's going well. Stopping is part of the system.
- **Type first, fix later.** Typos don't count while a box is being filled. Editing is a separate pass at the very end.
- **Stuck on a box?** Peek at the REFERENCE draft for that one section only, close it, then type yours.
- **Boxes can be filled out of order.** The proof has an order, but your typing doesn't have to. We'll arrange at the end.
- Word targets are guardrails, not quotas. Under is fine. Way over is fine too — cutting is the last step, not this one.
